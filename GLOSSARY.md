# CLARVIO glossary

| Term | Meaning |
| --- | --- |
| Workspace | The stable container for one customer request and its sources, conversation, and plans. |
| Source | A customer-uploaded file or pasted brief used as evidence. |
| Message | A customer or assistant turn in the clarification conversation. |
| Requirement | A requested outcome with evidence and acceptance criteria. |
| Assumption | A proposed condition that needs an explicit customer decision. |
| Plan version | An immutable snapshot of scope and delivery planning at one version number. |
| Task | A unit of proposed delivery work linked to confirmed requirements. |
| Assignment | A suggested or reviewed task owner with a matching rationale. |
| Approval | A manager decision bound to one exact plan version. |
